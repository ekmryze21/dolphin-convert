# Changelog

## 1.0.0

- New windows built on libadwaita, with the logo and light and dark themes
- Logo and a context menu icon
- Video: rotate, remove sound, extract subtitles
- PDF: merge, split, compress, recognize text
- E-books: EPUB, MOBI, AZW3, PDF, TXT
- Images: HEIC and camera RAW files as a source
- The installer offers to install missing packages and hides menus of missing tools
- The installer offers the full ffmpeg and the HEIC decoder from RPM Fusion on Fedora
- A clear message when ffmpeg lacks an encoder
- RPM and Arch package files
